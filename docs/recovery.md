# Recovery evidence

RFC 6330 Section 5.8 has two different obligations. A compliant decoder should
recover every mathematically sufficient receive set, and the standardized code
has mandatory average failure-rate bounds for random sets of K', K'+1, and
K'+2 encoding symbols.

The first obligation is tested deterministically. For eleven Table 2 sizes from
K'=10 through K'=101, `TestDecoderMatchesIndependentRankOracleBoundedCorpus`
builds random receive sets at overheads 0, 1, and 2. An independent
polynomial-arithmetic elimination oracle ranks the complete Figure 5 system.
The production decoder must complete exactly for full-rank systems and recover
the original bytes. Larger hybrid-domain loss/repair tests, the maximum-K
parity-checked loss/repair release test, and Rust/C++ cross-decoding extend this
evidence without pretending that finite tests prove every possible receive set.

The release profile is preregistered and reproducible:

- profile version: `rfc6330-section-5.8-v1`;
- K': 10, the first Table 2 row;
- ESI-pool seed: `0x633058015e8c0001`;
- pool: 65,536 distinct ESIs sampled uniformly from the 24-bit ESI domain;
- trials: 100,000 at overhead 0, 100,000 at overhead 1, and 3,000,000 at
  overhead 2;
- each trial samples distinct entries uniformly from that fixed pool; and
- interval: one-sided 95% Wilson upper bound.

The generator rows are derived from the RFC Figure 5 source matrix, and every
derived systematic row is required to be the matching unit vector before the
profile runs. Rank is then computed using a separate polynomial-reduction
GF(256) multiplication table. The golden report is
[`interop/corpus/recovery-profile.txt`](../interop/corpus/recovery-profile.txt)
and is regenerated by `task verify:recovery:release`.

All three recorded upper confidence bounds are below the corresponding RFC
limits. This is strong empirical evidence for the preregistered K'=10
population and sampler; it is not a universal statistical proof over all 477
Table 2 sizes or the entire 24-bit ESI population. Exact RFC row construction,
exhaustive primitive checks, external encoded-symbol parity, rank-sufficiency
tests, and the release-scale decoder cases provide the complementary evidence.
